# 巡檢與下載的獨立排程

IGWatcher 且啟用下載時，scheduler 使用兩個獨立到期時間，仍序列執行並保留 CLI 共用鎖。

- 巡檢依 `schedule.interval_minutes`，使用 `--inspect-only`，保存觀測但不啟動下載。
- 下載使用 `--download-pending`，每輪完成後 60 秒再次檢查；同時到期時先下載。
- 每帳號每輪上限、每筆間隔、單檔退避、查詢及媒體來源保護不變。
- 冷卻中不發來源請求；到期通常在下一分鐘檢查，但若另一工作仍執行或鎖被占用，會延後。
- Posts 需要刷新連結時仍受查詢冷卻限制，不透過拆排程繞過封鎖。
- 非 IGWatcher 或停用下載時沿用原排程。手動執行未帶模式的 CLI 保留原行為。

進度仍由逐筆下載日誌及原有 Telegram 摘要回報，本變更未加入每分鐘 Telegram 推播。
