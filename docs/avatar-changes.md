# 頭像內容與畫質變更

2026-09-12：修正只用檔案 SHA-256 比較頭像，導致同圖縮放或重新壓縮被通知為換頭像的問題。套用到正式監控流程；不改動一般媒體去重規則、來源歸屬狀態或其他個人資料的通知。

- 同內容、較低畫質版本：保留目前較佳檔案作為頭像，不發換圖通知。
- 同內容、較高畫質版本：更新頭像檔案與真正的 SHA-256，不發換圖通知。
- 內容不同或無法確認相同：沿用原本變更通知，包括變更前後附件。
- 追蹤者數、簡介等其他欄位變化照常通知。

比對只針對該帳號上一份快照及本輪頭像。先驗證兩份檔案與快照雜湊一致，再以 EXIF 方向校正、白底透明度合成後的影像比對：長寬比差異最多 1%、pHash 距離最多 4，64×64 RGB 全圖平均差每色頻最多 4，8×8 區塊平均差每色頻最多 12（色階範圍 0–255）。局部與顏色檢查用於降低單靠 pHash 忽略改色／覆蓋文字的風險；不做裁切配對或人臉辨識。

這是保守相似判定，不是對所有影像都能百分之百區分重新壓縮與細微編輯。壓縮或縮圖失真太大時，仍可能保留變更通知。品質以像素總數、其次檔案大小排序；兩者相同時保留目前版本，這些指標不保證能識別人工放大或失焦。

單檔比較上限為 20 MiB／400 萬像素，只比較靜態可解碼圖片；缺檔、雜湊不符、動畫、過大或無法解碼時，不隱藏原本的變更事件。沒有新增資料庫欄位，也不刪除歷史檔案或掃描歷史資料自動合併。頭像 URL 可以更新，而顯示路徑保留較佳本地版本。

已發出的誤報不會撤回。如果更新前目前快照已換成低畫質版本，本修正不自動搜尋舊檔還原；後續來源提供相同內容的較佳版本時會靜默升級。真的換圖後又換回歷史用圖，仍是變更，不能因曾下載過就忽略。

回歸測試使用人工影像，經真正的頭像保存、Monitor、SQLite 與事件流程，涵蓋降解析度、重新壓縮、升級後再次縮圖、其他資料同時變更、改色／裁切／加字、歷史用圖回復及舊檔損壞。未取得使用者這次的前後原始頭像，無法保證截圖所示個案已經原檔重播驗證。
