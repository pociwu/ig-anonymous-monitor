# 過期媒體連結的單筆處理

IGWatcher CDN 連結的 `oe` 值只視為時間提示，不是媒體刪除或作者歸屬證據。
在沒有走 Posts 刷新流程時，若允許的 CDN 網址帶有已過期的八位十六進位時間提示，先記錄單筆「待刷新」，不送出舊連結請求、不觸發來源冷卻。歷史資料保留，其他合格項目繼續。

未帶此提示、提示無法判讀、或刷新後仍遭拒絕的請求，沿用既有來源保護。429／驗證不降級為單檔失敗。
此變更尚未加入 Stories／Reels／Highlights 自動刷新；未能從目前來源找到的歷史內容仍會保留待處理。

批次每筆完成會記錄新增、重複、失敗與全部待處理數量。這是日誌進度，不是新的 Telegram 定時推播。
