# Limit phase one to public relationship monitoring

Phase one adds guarded `instagrapi` collection only for public-account Followers, Following, and mutual membership, plus change history and lazily enriched member profiles. Authenticated media, Reels, Stories, comments, likers, viewers, private-account data, Instagram write actions, and all Threads integrations remain out of scope until phase one has operated stably for at least 30 days and receives a new design approval.
