# 接受有明確限制的 IGWatcher 保存模式

2026-09-09 使用者接受：在來源缺少輪播子 ID、作者證據及完整精華回應時，仍保存可取得的內容，但不降低既有嚴格探針的驗收門檻。IGWatcher 內容先以來源查詢關聯存入獨立歸屬待確認區，不因媒體 ID 尾碼或檔案去重而提升為已驗證作者；正式來源仍須另行核准。

輪播以父貼文、觀測版本與位置建立明確的本地識別，URL 僅參與觀測版本的區分，不宣稱為內容或 Instagram 身分；相同下載位元組以 SHA-256 共用檔案。順序或 URL 改變會保留另一份觀測，不按永久位置覆寫歷史。精華保留歷次取得項目，顯示本次宣告數、回傳數與本地保存數；缺席不刪除，後續數量相等也不撤銷曾經不完整的紀錄。

代價是待確認內容不會自動轉正或發送媒體附件，URL 變動可能造成重抓與額外觀測紀錄，匿名來源的完整性仍未獲證明。此決策不取代 ADR 017 的無人值守要求。
