# ADR 016：跨帳號來源污染採非破壞性影片隔離

- 狀態：已接受
- 日期：2026-09-03

## 背景

匿名檢視來源曾把同一批影片錯配至多個互不相關的監控帳號。原有事故工具同時掃描照片
與影片，套用時會清除資料庫路徑並立即刪除檔案，無法讓操作人員保留真正屬於其中一個
帳號的原始影片。

## 決策

1. 跨帳號事故掃描預設只處理影片；照片與全部媒體必須以 CLI 明確選擇。
2. 相同 URL、相同 SHA-256，或既有 ffmpeg 三影格指紋相似且至少跨三個帳號時，列為來源污染候選。
3. 跨帳號事故規則不改變 ADR 003 的一般單帳號 Duplicate media 定義。
4. `--apply` 只將候選標記為隔離；不清除 `local_path`、不移動、不刪除任何檔案。
5. 隔離影片從一般相簿隱藏，並在 Dashboard 顯示影片、帳號群組、尺寸、時長、檔案大小與隔離時間。
6. 操作人員可逐筆選擇保留或永久刪除。保留會恢復隔離前狀態並建立人工信任決策；永久刪除保留資料庫墓碑，只有沒有其他有效紀錄引用相同路徑時才刪除檔案。
7. 缺少可用影片指紋時只使用 SHA-256 與 URL，不自動猜測感知相似。

## 後果

- 即使污染判斷有誤，套用隔離也不會造成資料遺失。
- 永久刪除需要逐筆人工確認，操作速度較慢，但能保留真正的原始影片。
- 舊影片沒有指紋時，重新編碼版本可能暫時無法被跨帳號比對。
