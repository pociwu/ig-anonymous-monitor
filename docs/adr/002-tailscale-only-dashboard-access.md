# ADR 002：以 Tailscale 限制未驗證的監控儀表板存取

- 狀態：已接受
- 日期：2026-07-29

## 背景

監控儀表板需直接監聽 `0.0.0.0:8888`，且使用者決定不設置網頁帳密或 HTTPS 反向代理。頁面會顯示巡檢帳號、Instagram Profile ID 與服務狀態。

## 決策

Flask 儀表板不實作應用程式層帳密驗證，直接提供 HTTP。存取只由 Tailscale ACL 管理；不另外設定 Ubuntu 主機防火牆規則。

## 後果

- 儀表板使用簡單，Tailscale 已授權裝置可直接存取。
- Tailscale ACL 必須拒絕未授權裝置對 TCP 8888 的存取。
- 儀表板不應新增可修改監控或服務的操作。
